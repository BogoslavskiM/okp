# Связанные чертежи КОМПАС

Папка содержит заново построенный комплект, геометрия видов которого связана с трехмерной моделью КОМПАС.

- `Модель/РЛ5.41.00.00.00_Связанная_модель.a3d` — корневая сборка; все 411 компонентов найдены.
- `Чертежи/` — четыре редактируемых CDW: ВО, ГЧ, СБ привода и СБ редуктора.
- `PDF/` — прямой экспорт этих CDW штатным конвертером КОМПАС `Pdf2d.dll`.
- `ОТЧЁТ_О_СВЯЗАННЫХ_ЧЕРТЕЖАХ.json` — машинная проверка связей, типов нативных объектов и посадок.
- `Модель/ПРОВЕРКА_СВЯЗЕЙ_МОДЕЛИ.json` — проверка зависимостей сборки.

На ВО посадка `⌀7 H7/h6` сохранена внутри нативного объекта диаметрального размера (`IDimensionText`), а не отдельным текстом. В СБ привода разрез В–В построен как ассоциативный разрез по нативной линии разреза.

Для переноса комплекта необходимо копировать всю папку `Связанные_КОМПАСС`, не отделяя CDW от каталога `Модель`.
