# Итоговый комплект ОКП

Чистовой учебный выпуск для изделия `РЛ5.41.00.00.00` — «Следящий привод возвратно-поступательного движения».

В комплекте находятся 8 редактируемых документов КОМПАС-3D (`6 CDW + 2 SPW`) и 8 одноимённых PDF (`11 листов`). Исходные материалы проекта не перезаписаны.

## Состав папки

- `Нативные_КОМПАС` — редактируемые CDW/SPW.
- `PDF` — контрольные PDF точных форматов A1/A2/A4; печатать 100 %, без «Вписать в страницу».
- `Модель` — проверенная копия STEP и протокол геометрического контроля.
- `Контроль` — ведомость, нормоконтроль, единый лист решений, машинные протоколы и увеличенные контрольные изображения.

Статус: косметический и файловый контроль — `PASS`. Инженерные пересчёты, прочностная проверка и производственное утверждение в задачу не входили.
